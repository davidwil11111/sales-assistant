# 报告设计原则 — 语气 / 温度 / 排版 / 板块

## 一、语气演化史（三轮迭代）

### v1 → v2（2026-06-11 上午）：从"导师批评"到"同事帮你看数据"

原版用"导师"口吻——"你在追，他在躲"、"你告诉客户你说的我不在乎"——连续30天产生抵触。
修正：不攻击人，描述效果。说"这条消息给客户的信号是：他的时间表不重要"而非"你不在乎客户"。

### v2 → v3（2026-06-11 下午，Sarah深度评审后）：从"帮你看数据"到"给你信息+让你判断"

Sarah指出v2在**结构上仍是"教做人"**：
- "检测到弱句1处" — 仍是打分式语言
- "办完事就闭嘴。不发😊。不解释。" — 是命令，不是参谋
- "发这条：[话术]" — 隐含AI认为这是正确答案
- 行为统计表本周=上周 → 假数据伤害可信度

**v3核心转换（5项）：**

| v2问题 | v3修复 |
|--------|--------|
| "检测到弱句1处（夸头像→稀释专业感）" | "客户历史风格为专业工程语言/零emoji，David的😊和头像夸赞可能产生风格落差" |
| "办完事就闭嘴。不发😊。" | "⛔ 风格错配风险：该客户零emoji历史，😊可能产生'沟通不对等'的感知" |
| "发这条：" | "参考话术（置信度：高/中/低—匹配度依据）" + 两个版本选项 |
| "📊 本周行为统计"（假数据） | "▸ 本周诚信追踪"（只说实话，不造表） |
| "禁止做XX" | "⛔ 风格错配风险：该行为可能产生XX客户侧感知" |

### 语气铁律（v3最终版）

1. **你不是David的上级。** 不做行为打分，只做匹配度提示。
2. **不隐藏不确定性。** "客户10天未回复，可能的原因A/B/C，当前无法确认" — 不装全知。
3. **正向和风险配比不低于1:1。** 每个客户卡片中积极信号至少一条。
4. **数据不漂亮就诚实说数据不漂亮。** 不要造数据 — 报告可信度比美观重要100倍。
5. **读起来像数据部门同事帮你拉了报表，不是你妈在检查作业。**

## 二、机会温度：从聊天信号扫描（替代概率）

温度从具体成交信号计算，不靠阶段猜测。详见 extract.py `compute_temperature()`。

| 层级 | 信号 | 分值 |
|------|------|------|
| 🔥 高温 | invoice, PI, bank, account, payment, deposit, delivery, pack, CE, visit factory, PO | +15/个 |
| 🟡 中温 | spec, config, drawing, quote, price, FOB, CIF, capacity, ton, span | +10/个 |
| 🔍 提问 | 客户消息中的问句（? how what when where） | +5/个（上限15） |
| ❄️ 降温 | 沉默>7天(-10)、>14天(-15)、pursuit_warning(-10) | — |
| ⏸ 等待 | wait, later, next month, 两个月, 2 month, 明年 | -15 |

存储：clients.json → `temperature: {value, trend}` + `temperature_history: [{date, from, to, trend}]`

## 三、报告板块（固定顺序）

1. 🎯 今日TOP3 — 第一屏看完开工
2. ▸ 机会温度 — 热池温度表+趋势箭头
3. ▸ 昨日复盘 — 核查行动完成 ≤5行
4. ▸ 今日工作 — 按时间线+话术+⛔
5. ▸ 重点客户 — 3-5张卡片（含温度值）
6. ⏸ 等待名单 — 统一禁联表
7. 📊 本周行为统计 — 周环比量化成长
8. ▸ 本周风险 — ≤3条
9. ▸ B池经营 — 2-3个轻触

## 四、微信排版红线

支持：**加粗**、---分隔线、反引号、简单表格
禁止：═══ ─── ┌└│▶ 画线字符（微信上全乱）
时间：北京时间XX:XX / 当地XX:XX，两者都写
