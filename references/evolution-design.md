# 进化机制设计 — 2026-06-09

**状态：✅ 已实施。** extract.py 四个新函数 + SKILL.md 进化循环章节 + 2个 cron job 全部就位。

32个客户深度分析后输出的完整进化机制设计。

## 设计原则

**专家框架 + 个人适配。** 不是二选一，是两层叠加。

- 底层（不动）：硬红线规则（追踪在线/性别幼化/💔/轰炸4+/承诺不兑现）— 我们的专家判断
- 顶层（新增）：个人风格指纹 — 适配每个销售员的自然节奏

**数据能回答的，不问人。只有风格判断才问人。**

## 三阶段设计

### 阶段0：观察期（前2周 / 前50个分析客户）

系统只观察不判断。不写coach_log，不批评。

生成 `data/style_profile.json`：平均消息长度、emoji频率、跟进间隔、每轮消息数、最常用收尾句式、语言混合比例、每种行为的回复率。

### 阶段1：激活期（2周后）

每条建议基于该用户自己的数据：

❌ 旧：不要用😊收尾
✅ 新：基于你的数据→😊收尾回复率14%，?收尾回复率65%。今天跟阿根廷的对话里客户等你下周报价→建议用?收。

硬红线仍然生效（追踪在线状态等直接标critical）。

### 阶段2：进化期（每月）

报告不是"你改没改"，而是"你的个人模式在变好还是变差"。

## 三层检测

### 第0层：硬红线（不动）
追踪在线状态、性别幼化、💔 -> 永久生效，不由数据调整

### 第1层：自动发现候选模式
extract.py 的 `discover_patterns()` 函数：
- count≥5 且 reply_rate<基线×0.3 -> 自动加入弱句监测
- count≥5 且 reply_rate=0% -> 自动加入+强制提醒
- count≥5 且 reply_rate≥基线 -> 明确排除，不是弱句
- count<5 -> 候选池，等数据累积

### 第2层：阈值自校准
每月 `calibrate_thresholds()` 测试 pursuit_threshold 3/4/5 的误报率+漏报率，推荐最优值。

## 文件驱动状态机

不依赖人记忆。文件存在与否驱动每一步：

### 数据文件（extract自动生成）
- `data/style_profile.json` — 个人风格指纹（含phrase_stats）
- `data/reply_stats.json` — 月度聚合统计+趋势
- `data/patterns_active.json` — 生效中的模式（含30天验证倒计时）
- `data/patterns_history.json` — 所有模式的一生

### cron job 驱动链
| 频率 | 动作 |
|------|------|
| 每天09:00 | 报告+自动裁决简报（30字，只读） |
| 每30天 | 扫描patterns_active.json → verify_at到了的 → 自动保留/移除+推送结果 |
| 每月1日 | 月度进化报告推微信 |

### 全自动裁决
```
发现"me.too" 6次0%回复
  → 自动加入弱句（不问人）
  → 通知："me.too已自动加入——6次0回复，30天后验证"
  → 30天后 cron 自动验证
  → 改善了→保留，没改善→自动移除+通知
```

## 每日报告升级

### 每日心率（30字，报告第零部分之前）
本周话术回复率X% ↑↓ | 追客户X次 ↑↓ | ⚠️顽固模式提醒

### 自动裁决简报
今日自动加入/移除/候选的模式一览。只读，不需要David操作。

### 专项训练（连续3周某模式无改善触发）
下周每日报告针对该模式每天给一个具体练习（带正确/错误示范）。

## 月度进化报告结构（每月1日推送微信）

- 📈 关键数字 vs 上月
- 🏆 本月最佳3个对话（附原文片段）
- 📉 退步项
- ⚠️ 顽固问题（连续3月→标红，触发下月专项训练）
- 🔧 下月重点（选1个模式攻克）
- 🎯 目标设定
- 🔧 阈值校准建议

## 问人的唯一场景：风格声明

```
你的风格指纹：友好型销售
- 平均消息45词
- emoji使用频率70%
- 倾向于用"friend"称呼客户
确认→按此风格优化   调整→选你想改的方向
```
