# Sarah 早会 — 每日报告格式设计决策

历经三轮迭代：v1 系统仪表盘 → v2 导师晨会 → v3 参谋早会（当前版本）。

## 设计转变

v1→v2（2026-06-10）：从冷冰冰的emoji列表改为导师晨会。
v2→v3（2026-06-11 下午，Sarah深度评审）：从"教做人/发号施令"改为"参谋/给信息+让销售判断"。

**v3核心原则：**

1. **Sarah 是参谋，不是上级。** 不做行为打分，只做匹配度提示。不写"你做错了"，写"该客户历史风格为X，你的消息风格为Y，存在错配风险"。
2. **不确定就说不知道。** "客户10天未回复，可能的原因：A内部审批/B出差/C对比别家，当前无法确认"——不装全知。
3. **AI可能看错置顶。** 报告第一屏列出今天最不确定的判断，给备选解释。让销售使用报告前有校准框架。
4. **数据不漂亮就诚实。** 不造表，不编趋势箭头。本周和上周一样就说"暂无对比数据"。
5. **话术给选项不给唯一答案。** 每句话术带置信度+匹配度依据。风格不确定时给两个版本（激进/保守），各标风险。
6. **积极信号不少于风险。** 每个客户卡片中正面和负面信息配比不低于1:1。销售每天需要正反馈。

## 十大板块（固定顺序）

```
⚠️ AI今日判断的不确定性	— 报告第一屏。1-3个最不确定的判断+备选解释
🎯 今日TOP3			— 看完直接开工，3个行动
▸ 机会温度			— 温度定义+热池表（温度=0-100信号活跃度，非概率）
▸ 昨日复盘			— ≤5行事实
▸ 今日工作			— 时间线+方向+话术+置信度+⛔风格错配风险
▸ 重点客户			— 3-5张卡片（事实/观察/积极信号/动作/置信度/AI可能看错）
▸ 待激活线索			— 有明确联系窗口的人（与B池经营的区别见规则说明）
▸ 承诺与兑现追踪			— 只说真话：哪些承诺逾期了，客户侧感知是什么
▸ 本周风险			— ≤3条
▸ 待激活线索经营		— 2-3个B池轻触（方向+低置信度话术）
📌 今日一句话
```

## 排版规范

支持：**加粗**、---分隔线、反引号话术、简单markdown表格
禁止：═══ ─── ┌└│▶ 等画线字符（微信全乱）
时间：**北京时间XX:XX / 当地XX:XX**，两者都写

## ⛔ 风格错配风险 标记的用法

不写"禁止"/"不能做"/"避免"，写"⛔ 风格错配风险：[可能产生的客户侧感知]"。

例如：
- 旧："禁止解释延迟原因。发😊。" → 命令式
- 新："⛔ 风格错配风险：该客户零emoji历史，😊可能被感知为不专业。解释延迟可能被读作找借口。" → 信息式

## 关键教训

- 2026-06-10：先写模板没出样本，被纠正。→ 系统改造铁律第4条：格式/文案改动必须先出样本。
- 2026-06-11 上午：微信画线字符═══在微信全乱。→ 只允许 --- 和加粗。
- 2026-06-11 下午（本次）：Sarah指出v2虽改了措辞但结构上仍是"教做人"。核心教训：**措辞温和化≠去了评判味。真正的去评判需要：(1)AI不确定区置顶 (2)话术带置信度不给唯一答案 (3)⛔不写"禁止"写"可能产生XX感知" (4)删除假数据改为诚实陈述。**
