# 小虾早会 — 微信报告格式决策

## 为什么是微信原生格式

第一次设计用了 ═══ ─── ┌└│▶ 等画线字符 → 微信上全部乱码。
WeChat 聊天界面只支持 Markdown 子集：**加粗**、`代码块`、--- 分隔线。

## 正确格式

| 元素 | 用法 | 示例 |
|------|------|------|
| 板块标题 | `**▸ 标题**` | **▸ 昨日复盘** |
| 分隔线 | `---`（单独一行） | 微信渲染为分隔线 |
| 意向标记 | 🔴🟡⚪ 开头 | **🔴 Edgar · 秘鲁 · 临门一脚** |
| 话术 | 反引号包裹 | \`Edgar, the invoice is ready.\` |
| 禁令 | ⛔ 开头 | ⛔ 不解释不道歉 |
| 风险 | ⚠ 开头 | ⚠ Edgar · 不处理3天后丢单 |
| 时间 | 双时区加粗 | **北京时间10:00 / 埃及9:00** |

## 禁止使用的字符

═ ═ ═ ─ ─ ─ ┌ └ │ ├ ┤ ┬ ┴ ┼ ▶ ▸ ▪ ▫ ◆ ◇
这些在微信上不渲染或错位，一个都不用。

## 报告结构（7板块固定顺序）

1. **▸ 昨日复盘** — 核查昨天做了什么、兑现了什么
2. **▸ 今日工作** — 按时段排列（现在/上午/今晚/不联系）
3. **▸ 重点客户** — 3-5个客户卡片，🔴🟡⚪标记
4. **▸ 不能做的事** — 客户+原因+解禁时间
5. **▸ 本周风险** — 不超过3条，说明后果
6. **▸ 导师提醒** — 一条具体训练指令
7. **▸ B池经营** — 2-3个最久未联系的B池客户

## 风格

- 3分钟内读完
- 导师语气——直接、批评、不客套
- 话术直接复制可发
- 不质疑产品范围（所有者说能卖就能卖）
