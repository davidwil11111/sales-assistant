# 外贸销售阶段参考

## 销售漏斗五阶段

### 1️⃣ Awareness (认知)
**客户行为特征:**
- 刚通过 WhatsApp 加好友
- 简单问候或自我介绍
- 浏览你的产品动态
- 偶尔点赞/评论

**销售目标:** 建立第一印象，了解客户背景
**Sarah 建议:** 问候要专业但不压迫，先了解对方是做代理还是终端用户

### 2️⃣ Interest (兴趣)
**客户行为特征:**
- 询问"你们做什么产品"
- 要产品手册/目录
- 问"价格大概多少"
- 问"你们卖到哪些国家"

**销售目标:** 获取需求信息，展示专业度
**Sarah 建议:** 别急着报价！先问清楚规格、参数、使用场景，精准推荐才显专业

### 3️⃣ Evaluation (评估)
**客户行为特征:**
- 详细问规格参数
- 要求报价单
- 问"和其他品牌比有什么优势"
- 问"你们有认证吗"
- 要参考案例

**销售目标:** 突出差异化优势，消除疑虑
**Sarah 建议:** 发比较表 + 视频展示工厂/质检流程，眼见为实

### 4️⃣ Negotiation (谈判)
**客户行为特征:**
- 议价："价格太贵了"
- 谈付款方式"能做LC吗"
- 问交期
- 问质保和售后
- 要求拆分报价

**销售目标:** 促成签约，灵活让步
**Sarah 建议:** 不要直接降价，用"价值让步"——送配件包、延保、免运费等

### 5️⃣ Decision (决策)
**客户行为特征:**
- 确认规格
- 催 PI/合同
- 确认 shipping mark
- 问安装调试
- 推荐给朋友

**销售目标:** 快速出单，完美交付
**Sarah 建议:** 迅速出 PI，保持响应速度，给客户"选对了"的感觉

## 意向等级判断标准

### 🔥 高意向
- 主动询价且要报价单
- 问具体参数：吨位、跨度、起升高度
- 要求发 PI
- 主动告知项目时间线
- 讨论付款和交期细节

### ⚡ 中意向
- 要产品手册/目录
- 问大致价格范围
- 提问关于认证/运输
- 正在进行项目需要采购设备

### 💤 低意向
- 简单添加好友
- 偶发消息但未涉及业务
- 已读不回
- 长期未联系

## 起重机外贸话术要点

1. **开场白**：亮明身份 + 公司优势 + 开放性问题
2. **需求挖掘**：吨位 → 跨度 → 工作级别 → 环境 → 预算
3. **优势展示**：工厂直供 + 认证齐全 + 海外案例 + 售后保障
4. **异议处理**：别直接降价，用价值组合拳
5. **促成**：制造紧迫感（限时优惠/交期窗口）+ 降低决策门槛

## 常见客户类型

| 类型 | 特征 | 策略 |
|------|------|------|
| 🏭 终端用户 | 买来自己用，要详细参数 | 精准推荐，强调质量和售后 |
| 🏢 经销商 | 批量采购转售，看重价格 | 阶梯价格，保护区域代理 |
| 👷 工程公司 | 项目制，需要定制方案 | 技术方案配合，强调EPC经验 |
| 🔍 咨询方 | 帮甲方找供应商 | 快速专业响应，提供完整资料 |
