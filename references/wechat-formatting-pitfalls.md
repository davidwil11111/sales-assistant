# 微信排版陷阱

## 核心规则

微信（WeChat）聊天窗口只支持有限的 Markdown：
- **加粗** ✅
- `---` 分隔线 ✅（三个短横线）
- 反引号代码 ✅
- 链接 ✅

**以下字符在微信上排版完全崩溃，永远不要用：**

| 字符 | 用途 | 微信表现 |
|------|------|---------|
| ═══ | 双线分隔 | 乱码/错位 |
| ─── | 单线分隔 | 乱码/错位 |
| ┌ └ │ ├ ┤ ┬ ┴ ┼ | 表格框线 | 全乱 |
| ▶ ▷ ► | 箭头标记 | 不渲染/占位异常 |
| ◉ ◎ ○ ● | 项目符号 | 大小不一致 |

**替代方案：**

| 旧（画线字符） | 新（微信原生） |
|---------------|---------------|
| ══════════ | `---` |
| ───────────────── | `---` |
| ┌ 客户卡片 └ | **客户名** · 国家 |
| ▶ 行动项 | **现在立刻** |
| 🚫 禁令 | ⛔ 禁令 |

## 报告模板必须遵守

SKILL.md 中的每日报告格式模板已经全部改为微信原生 Markdown。
生成报告时严格按模板，不要自创画线字符。

## 教训

2026-06-10：第一次设计报告格式用了 ═══ ─── ┌└│▶，用户在微信上看到排版混乱。
马上出样本给用户确认，而不是直接写入 SKILL.md。
